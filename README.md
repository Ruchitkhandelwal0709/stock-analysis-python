# Stock Analysis & Comparison Tool

## Overview

A Python based stock analysis project that compares two stocks using historical market data and fundamental metrics.

The project allows users to enter two stock names and analyzes their performance, risk, fundamentals, and overall score.

# Features

- Historical stock price analysis
- Investment value calculation
- Return calculation
- Volatility analysis
- Maximum drawdown analysis
- Average daily return
- Fundamental analysis
- Operating margin comparison
- Net profit margin comparison
- Fundamental scoring
- Weighted overall scoring
- Two-stock comparison
- Final investment verdict

# Technologies Used

- Python
- yfinance
- Pandas

# How It Works

1. User enters two stock names.
2. The program fetches historical market data.
3. Returns and volatility are calculated.
4. Fundamental metrics are analyzed.
5. Both stocks are compared.
6. Fundamental and weighted scores are calculated.
7. The program generates a final comparison and verdict.
